# 🍷 Wine Quality Prediction 

A machine learning project developed during my **Data Analytics Internship at Oasis Infobyte**. This project focuses on predicting wine quality based on its physicochemical properties using multiple classification algorithms and comparing their performance.

---

## 📌 Project Overview

Wine quality depends on several chemical properties such as acidity, alcohol content, pH, density, sulphates, and more. In this project, I performed data preprocessing, exploratory data analysis (EDA), feature engineering, and trained multiple machine learning models to classify wine quality.

The goal was to evaluate different classification algorithms and determine the most suitable model for accurate wine quality prediction.

---

## 🎯 Objectives

- Load and understand the Wine Quality dataset.
- Perform Exploratory Data Analysis (EDA).
- Preprocess the dataset for machine learning.
- Train multiple classification models.
- Evaluate and compare model performance.
- Identify the best-performing classifier.
